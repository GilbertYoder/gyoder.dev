simplezip.dev is a no-account / no-api-key required ZIP code API. I was working on a project and needed an endpoint to fetch coordinates and city/state info per zip code. Not finding any active projects (free ones that is) I decided to build my own.

What I like about simplezip.dev is the simplicity. Hosted on github pages, it is purely a repository of json files. The data is sourced from www.geonames.org and organized into json files using a small script.
